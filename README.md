# 🛡️ TeenSafe

> **"TeenSafe is a consent-based, teen-first digital safety platform that replaces surveillance with education and self-awareness."**

TeenSafe rethinks minor digital safety: instead of secret parental spy-software that logs chats and damages trust, the teen owns their account. The teen earns a holistic **Safety Score (0–100)** through scenario-based learning, active threat scanning, and good digital habits, sharing only aggregate milestones with parents.

---

## 🎯 The Central Spine: The Safety Score (0–100)

Every module connects into this single index:

| Activity | Impact on Safety Score | Educational Rationale |
| :--- | :--- | :--- |
| **Complete a Lesson** | `+10 to +25 points` | Proactive knowledge foundation |
| **Scenario Quiz Accuracy** | `+5 to +15 points` | Practical dilemma decision-making |
| **Spot Threat in AI Scanner** | `+2 to +5 points` | Building active verification habits |
| **Learning Streak (Consecutive Days)** | `Bonus multipliers` | Habitual digital wellness |

---

## 🧩 The 4 Core Modules

1. **Module 1 — Learn & Play (Interactive Curriculum)**
   - 5 core topics: Cyberbullying, Phishing/Scams, Passwords & Privacy, Fake Profiles, Screen Time.
   - Scenario-based MCQs with instant pedagogical explanations and score increments.

2. **Module 2 — AI Risk Scanner ⭐ (Deep ML Feature)**
   - Minors paste suspicious text, DMs, or URLs.
   - **Text Classifier:** Detects cyberbullying patterns, urgent financial scam keywords, and normal communication.
   - **URL Rule Engine:** Identifies lookalike domains (`faceb00k`, `paypa1`), suspicious TLDs (`.xyz`, `.top`), IP-based hosts, non-HTTPS protocols, and credential `@` tricks.
   - **🔒 Privacy by Design:** Scanned text is evaluated strictly in-memory and immediately destroyed. Only the categorical risk label and confidence score are saved in `ScanHistory`.

3. **Module 3 — Parent–Teen Bridge (Consent-Based)**
   - 6-digit invite code generated by the teen.
   - Parent sees: Safety Score, completed modules, weak topics, and last-active timestamp.
   - Teen can unlink at any time with zero lock-in.

4. **Module 4 — Report & Crisis Support**
   - Confidential / Anonymous incident reporting form.
   - Directory of official emergency cyber helplines (National Cyber Crime 1930, Childline 1098, KIRAN Helpline).

## 🛠️ Tech Stack

- **Frontend & API:** Next.js 15 (App Router), React 19, TypeScript
- **Styling & UI:** Tailwind CSS, Lucide Icons, Modern Dark Mode UI
- **Database & ORM:** PostgreSQL (Neon.tech / Supabase compatible), Prisma ORM
- **Authentication:** Role-Based Access Control (`TEEN`, `PARENT`, `ADMIN`) with secure JWT sessions
- **AI Microservice:** Python 3, FastAPI, scikit-learn (TF-IDF + Linear Classifier)

## 🚀 Quick Start

### 1. Web Application (Next.js)

```bash
# Install dependencies
npm install

# Setup environment variables
cp .env.example .env

# Validate and generate Prisma client
npx prisma generate

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. AI Risk Scanner Microservice (FastAPI)

```bash
cd fastapi-service
python -m venv venv
venv\Scripts\activate   # Windows
pip install -r requirements.txt
uvicorn app:app --reload --port 8000
```

## 🧪 Mentor Demonstration Guide (Phase 1)

1. **Sign In**: Navigate to `/login`. Use the one-click demo pills:
   - **Teen Account**: `teen.alex@example.com` / `SafeTeen2026!`
   - **Parent Account**: `parent.smith@example.com` / `SafeParent2026!`
2. **Dashboard Overview**: View the circular Safety Score (0–100) and contribution breakdown.
3. **Module 1 (Learn & Quiz)**: Open `/dashboard/learn/cyberbullying`. Review the lesson, click *Test Knowledge*, select scenario answers, and observe real-time feedback and explanations.
4. **Module 2 (AI Risk Scanner)**: Open `/dashboard/scanner`. Click one-click sample buttons (Scam SMS, Cyberbullying Threat, Typo-squatting Link) to demonstrate immediate AI threat classification.
5. **Ethics & Minor Privacy**: Point out that message payloads are dropped in-memory and parents never see private messages.
