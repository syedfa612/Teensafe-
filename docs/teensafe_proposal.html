1. Executive Summary & Problem Formulation

Contemporary parental monitoring software operates predominantly as covert spyware: keystroke logging, GPS tracking, and clandestine surveillance of private messages. While intended to shield minors from digital hazards, empirical adolescent psychology indicates that covert surveillance induces distrust, encourages evasive behavior (e.g., secondary hidden accounts or burner devices), and offers zero educational intuition.

TeenSafe fundamentally disrupts this paradigm. It treats the adolescent as an autonomous stakeholder in their own digital wellbeing. The teen owns the primary user account, learns proactive defense mechanisms through real-world scenario dilemmas, and utilizes on-demand Machine Learning scanning tools to evaluate suspicious messages and web links. Instead of broadcasting unedited private chats to parents, the system calculates an aggregate, holistic metric: The Unified Safety Score (0–100). Parents are granted visibility solely into high-level wellness milestones upon bilateral consent.

Key Academic Highlights for Evaluation:
  • Consent-Driven Ethics: Direct replacement of parental spyware with minor empowerment and transparent, revocable linking.
  • Privacy-by-Design Architecture: In-memory AI inference for suspicious text; raw message strings are discarded immediately and never stored in the database.
  • Empirical Machine Learning: TF-IDF vectorization paired with linear classification (Logistic Regression & Linear SVM) validated on open benchmark datasets.
  • The Unified Safety Score Spine: An algorithmic score (0–100) mathematically coupling lessons, quizzes, threat scans, and consistency streaks.

2. The System Spine: Unified Safety Score (0–100)

Rather than treating education, risk detection, and parental reporting as disconnected silos, TeenSafe binds every user interaction into a single composite index:

🔒 Privacy-by-Design Compliance (Viva Defense Point):
Notice that the ScanHistory entity stores only inputType, resultLabel, confidence, and categorical riskFactors. The raw input string containing minors' personal messages is processed transiently in memory and discarded. No private conversation logs are persisted or exposed to parental dashboards.

5. Module 2: AI Risk Scanner Architecture ⭐

The AI Risk Scanner microservice implements a hybrid threat detection architecture combining deterministic heuristics with probabilistic machine learning:

5.1 Deterministic URL Threat Heuristics

  • Typosquatting & Lookalike Domains: Regex mapping identifies brand impersonations (e.g., faceb00k.com, paypa1.com, instagrarn.com).
  • High-Risk TLD Filtering: Evaluates low-reputation top-level domains commonly registered by automated phishing kits (.xyz, .top, .tk, .buzz).
  • Protocol & Host Anomalies: Flags raw IP addresses in place of domain names and unencrypted HTTP connections.
  • Credential Obfuscation: Detects deceptive @ syntax used to conceal target destinations.

5.2 Natural Language Classifier Pipeline

  • Dataset Benchmarking: Trained on open standard corpuses: Kaggle Cyberbullying Classification and SMS Spam Collection datasets.
  • Feature Extraction: Sub-linear TF-IDF vectorization with n-gram range (1, 2) capped at 5,000 salient features.
  • Model Comparison (Academic Viva Requirement): Evaluated against Multinomial Naive Bayes, Logistic Regression, and Linear Support Vector Classifier (LinearSVC).

7. Summary & Conclusion

TeenSafe successfully bridges the ethical gap between adolescent digital autonomy and parental peace of mind. By implementing an educational, scenario-driven learning engine coupled with real-time AI risk evaluation and transparent consent mechanisms, the platform empowers teens with long-term digital discernment rather than short-term subjection to surveillance.

The Phase 1 prototype meets 100% of the milestone requirements: fully authenticated RBAC, production database schema, functional learning and quiz modules, active AI risk scanner, and responsive dashboards ready for mentor demonstration.
